# Product Video Scripts — Short Form

Short-form product/demo scripts for YouTube Shorts, Instagram Reels, LinkedIn, and X. Shared rules, screen map, compliance, brand tone, music, and the demo account data live in [`product-common.md`](product-common.md) — read it first. Long-form companions are in [`product-long-form-scripts.md`](product-long-form-scripts.md).

**Every script here is fully elaborated for recording.** Each one includes a **Recording Instructions** table with the exact screen, where to find it, and step-by-step navigation — plus screenshot guidance for the one frame that must land. The app is at `https://app.docita.work`; demo names follow the Demo Account Data Template in [`product-common.md`](product-common.md). Read the "How to read the short-form scene tables" section in that file once before recording.

These shorts can be **cut from long-form footage** (record once, cut many) or **recorded standalone** using the navigation steps below.

**Index by theme**

- A. Intro and trial — Shorts 1–6
- B. Setup and adoption — Shorts 7–15
- C. Doctor value — Shorts 16–21
- D. Front desk value — Shorts 22–28
- E. Owner value — Shorts 29–34
- F. The connected journey — Shorts 35–39
- G. WhatsApp and communication — Shorts 40–43
- H. Scale: multi-doctor, multi-clinic, hospital — Shorts 44–47
- I. Specialized: lab, documents, booking, security — Shorts 48–52
