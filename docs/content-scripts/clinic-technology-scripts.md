# Clinic Technology Scripts

Short-form video scripts covering digital prescriptions, patient records, billing, WhatsApp workflows, clinic software, import from Excel, and technology adoption for clinics. Each script is 15–60 seconds.

Every script includes **detailed scene recording instructions** with exact URLs, navigation steps, and screenshot guidance so the person recording knows exactly where to go and what to capture.

---
