## How to Use in the System

### In Invoicing

1. Navigate to: `Invoices → Create Invoice`
2. Click "Add Procedure"
3. Search by code (e.g., "D2391") or description (e.g., "composite")
4. Select from autocomplete list
5. System auto-fills description and typical price
6. Adjust price if needed
7. Add quantity
8. Save

### In Treatment Planning

```typescript
// Example treatment plan with codes
"Phase 1: Emergency
 - D3330: RCT molar #46
 - Rx: Amoxicillin 500mg Q8H x 7 days

Phase 2: Restorative
 - D2392: Composite 2 surf #14 (DO)
 - D2393: Composite 3 surf #15 (MOD)

Phase 3: Periodontal
 - D4341 x 4: Full mouth SRP

Phase 4: Prosth
 - D2750: PFM crown #46"
```

### In Documentation

- Reference CDT codes in clinical notes
- Include in treatment plans
- Use for insurance pre-authorization

## Common Code Combinations

### Root Canal Treatment (Complete)

```
D3330: RCT - molar
D2950: Post and core (if needed)
D2750: PFM crown
```

### Full Mouth Rehabilitation

```
D0150: Comprehensive exam
D0330: Panoramic X-ray
D0210: Full mouth X-rays
D1110: Prophylaxis
D4341 x 4: SRP all quadrants
Multiple crowns/fillings as needed
```

### Wisdom Teeth Removal (All 4)

```
D7230 or D7240 x 4 (depending on impaction)
D0330: Panoramic X-ray (pre-op)
```

### Implant Treatment (Single Tooth)

```
D6010: Implant placement
D6056: Abutment
D6058: Implant crown
```

## Insurance Billing Tips

### Required for Claims

- Correct CDT/CPT code
- Tooth number (for tooth-specific procedures)
- Surface(s) treated (for restorative)
- Date of service
- Provider NPI number
- Diagnosis code (ICD-10)

### Pre-Authorization

Codes often requiring pre-auth:

- D2740-D2799: Crowns
- D3000-D3999: Endodontics
- D4000-D4999: Periodontal surgery
- D6000-D6999: Implants
- D7200-D7299: Surgical extractions

### Frequency Limitations

- D1110/D1120: Typically 2x per year
- D0274: Typically 1x per year
- D0330: Typically 1x per 3-5 years
