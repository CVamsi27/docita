# Docita Pricing Plan - Usage-Based Model

## Overview

This document outlines the new usage-based pricing structure for Docita, designed following modern SaaS pricing principles with base costs, usage-based components, and add-ons.

---

## Supported Currencies

Docita supports pricing in 5 major currencies:

| Currency          | Symbol | Code |
| ----------------- | ------ | ---- |
| Indian Rupee      | ₹      | INR  |
| US Dollar         | $      | USD  |
| Euro              | €      | EUR  |
| British Pound     | £      | GBP  |
| Australian Dollar | A$     | AUD  |

The pricing page automatically detects user location and shows appropriate currency. Users can also manually switch currencies.

---

## Pricing Philosophy

1. **Base + Usage Model**: Each tier has a base price with included quotas, additional usage billed per unit
2. **Transparent Pricing**: Clear per-unit costs for overages
3. **Add-ons**: WhatsApp and AI Intelligence as separate purchasable modules
4. **Discounts**: Yearly commitment and referral incentives
5. **Multi-Currency**: Localized pricing in 5 major currencies

## Billing Technical Details

### Metering Strategy

```
Usage Period: Calendar month
Billing Date: 1st of each month
Grace Period: 7 days for payment
Overage Calculation: Real-time, billed at end of period
```

### Usage Tracking Events

```typescript
interface UsageEvent {
  clinicId: string;
  eventType:
    | "patient_active"
    | "appointment_created"
    | "whatsapp_sent"
    | "ai_credit_used";
  quantity: number;
  timestamp: Date;
  metadata: Record<string, any>;
}
```

### Patient Counting Rules

- **Active Patient**: Any patient with activity in the billing period
- Activity = appointment, prescription, visit, or record update
- Inactive patients don't count toward limit
- Archived patients don't count

## Appendix: Price Sensitivity Research

Based on Indian healthcare market:

- Solo practitioners: ₹500-2,000/mo budget
- Small clinics (2-3 doctors): ₹2,000-5,000/mo budget
- Multi-specialty: ₹5,000-15,000/mo budget
- Hospitals: ₹15,000-50,000+/mo budget

WhatsApp messaging is high-value:

- 85% of Indian patients prefer WhatsApp
- Reduces no-shows by 30-40%
- High willingness to pay for automation

AI features:

- Premium positioning justified
- Early adopter clinics willing to pay premium
- Voice-to-text highly valued (saves 15-20 min/patient)
